# Audio drop-in folder

아래 이름으로 파일을 넣으면 코드 변경 없이 재생됩니다.

- `bgm-menu.mp3` — 로비/커뮤니티 배경음, 반복 재생
- `bgm-run.mp3` — 게임 중 배경음, 반복 재생
- `bgm-boss.mp3` — 보스 라운드 배경음, 반복 재생
- `card-select.mp3` — 카드 선택
- `card-play.mp3` — 핸드 제출
- `score.mp3` — 점수 확정
- `buy.mp3` — 상점 구매
- `uno.mp3` — UNO 발동
- `win.mp3` — 라운드 또는 런 승리
- `lose.mp3` — 패배

파일이 없어도 게임은 오류 없이 동작합니다. 설정의 음악·효과음 슬라이더가 이 경로의 오디오에 적용됩니다.
